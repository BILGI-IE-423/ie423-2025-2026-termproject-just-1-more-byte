## Research Questions

1. Which MBTI personality dimensions are most predictable from text?
2. Which linguistic and stylistic features contribute most to personality prediction?
3. Can personality traits still be predicted when topical vocabulary is removed?

## Running the Pipeline

Run from the **project root** directory.

### Full pipeline

```bash
python scripts/run_pipeline.py
```

Runs stages **01 → 08** in order.

| Stage | Script | Description |
|-------|--------|-------------|
| 01 | `preprocessing/01_load_data.py` | Load and inspect raw data |
| 02 | `preprocessing/02_preprocess_data.py` | Clean and preprocess |
| 03 | `visualization/03_basic_eda.py` | Exploratory data analysis |
| 04 | `feature_engineering/04_build_tfidf.py` | TF-IDF features + split |
| 05 | `feature_engineering/05_build_style_features.py` | RQ3 placeholder |
| 06 | `modeling/06_train_models.py` | Train classifiers |
| 07 | `evaluation/07_evaluate_models.py` | Evaluate models |
| 08 | `visualization/08_interpretability_analysis.py` | Interpretability figures |

### Skip preprocessing (start from TF-IDF)

```bash
python scripts/run_pipeline.py --from 04
```

### Run a single stage

```bash
python scripts/run_pipeline.py --stage 07
```

### Individual scripts

```bash
python scripts/preprocessing/01_load_data.py
python scripts/preprocessing/02_preprocess_data.py
python scripts/visualization/03_basic_eda.py
python scripts/feature_engineering/04_build_tfidf.py
python scripts/feature_engineering/05_build_style_features.py
python scripts/modeling/06_train_models.py
python scripts/evaluation/07_evaluate_models.py
python scripts/visualization/08_interpretability_analysis.py
```

> **Note:** Place `mbti_1.csv` in `data/raw/` before running. See [`data/README.md`](data/README.md) for download instructions.

## Models

Four binary classification tasks (I/E, N/S, T/F, J/P), each trained with:

| Model | sklearn class |
|-------|---------------|
| Logistic Regression | `LogisticRegression(class_weight='balanced')` |
| Linear SVM | `LinearSVC(class_weight='balanced')` |
| Random Forest | `RandomForestClassifier(class_weight='balanced')` |

Features: TF-IDF (max_features=5000, English stopwords).  
Split: 80/20 stratified on MBTI type, `random_state=42`.

---

## Evaluation

Primary metric: **Macro F1-score**

Also computed: Accuracy, Precision, Recall, ROC-AUC, Confusion Matrix
